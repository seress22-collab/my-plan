# 나의 플래너 - 놓치지 않을거에요!

할 일 체크리스트 · 메모 · 아이디어 · 1년 플래너를 한곳에 모은 개인용 웹앱입니다.
서버 없이 동작하며, 데이터는 사용하는 기기의 브라우저(localStorage)에만 저장됩니다.

- 앱 주소: https://seress22-collab.github.io/my-plan/
- 휴대폰에서 열고 “홈 화면에 추가”하면 앱처럼 쓸 수 있습니다.
- 앱 파일은 `나의 플래너/` 폴더에 있고, `main`에 올리면 GitHub Pages로 자동 배포됩니다.

## 주요 기능

- **분류**: 회사 · 학교 · 공모전 · 개인 · 미팅 (설정에서 추가·이름·색 변경)
- **빠른 입력**: `내일 3시 팀 회의 @미팅 #기획`, `10/20 공모전 제출 @공모전`, `다음주 월요일 운동`
- **할 일**: 기한·시간, 세부 체크리스트, 반복(매일/매주/매월/매년), 중요 표시, 태그
- **알림**: 마감 전날 · 당일 아침 · 1시간 전, 아침 브리핑, 저녁 “못 끝낸 일” 점검, 기한 지난 미완료 배지
- **1년 플래너**: 연간 목표, 월별 목표·달력·월 메모, 마일스톤 / 월초·월말(3일 전)·상반기·연말 점검 알림
- **메모**: 첫 줄이 제목, `#태그` 자동 색인, ㄱㄴㄷ 초성 색인 · 태그별 · 분류별 보기
- **아이디어 보관함**: 한 줄 바로 담기, ⭐ 중요, 씨앗 → 발전 중 → 실행함, 할 일로 전환
- **전체 검색**: 할 일·메모·아이디어·목표 통합 검색, 초성 검색(예: `ㄱㅁㅈ`), `/` 단축키
- **디자인**: 포레스트 민트(기본) · 블루 · 코랄, 밝게/어둡게
- **백업**: JSON 백업/복원, 캘린더(.ics) 내보내기(전날·당일 알람 포함)

## 알림 참고

브라우저 알림은 앱이 열려 있거나(백그라운드 탭 포함) 다시 열 때 울립니다.
앱을 닫아 둬도 반드시 울려야 하는 일정은 설정 → “캘린더로 내보내기”로 휴대폰·구글 캘린더에 넣어 두세요.
